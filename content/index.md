# EchoJustus

Notes, guides, and posts — a knowledge base built with
[clogem-press](https://github.com/EchoJustus/clogem-press).

This page is `content/index.md`, the one Markdown file that is never numbered
and never gets a permalink. Edit it freely: everything below the front-matter
block is rendered as the home page body. The `home: true` marker is the
convention for a home page and is worth keeping, though the current generator
does not act on it — files directly under `content/` are not scanned as
articles in the first place, so this file is already exempt.

The site is published in five languages — English, 简体中文, 繁體中文, Bahasa
Melayu and தமிழ் — and the language switcher sits in the navbar of every home
page. A page appears in a language when a file for that language exists;
nothing is machine-translated. To give this home page a Chinese version, add
`content/index.zh-Hans.md` beside this file.

## Where things live

- `content/01.Notes/` — the numbered knowledge-base tree.
- `content/_posts/` — dated blog posts.
- `assets/` — static files, copied through to the site root under `/assets/`.
- `README.md` — the authoring conventions, in one page.
