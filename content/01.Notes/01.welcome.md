# Welcome

This is a starter article. It lives at
`content/01.Notes/01.welcome.md`, which is the shape every article in the
knowledge-base tree takes:

- `01.Notes` is a **numbered directory**. The number sets its position in the
  sidebar; the text after the first dot is the category name, so this article's
  category is *Notes*.
- `01.welcome.md` is a **numbered file**. The number sets its position within
  the directory; the text between the first and the last dot is the title used
  when the front matter does not give one.

The front matter above started as a single `title:` line. Everything else —
`date`, `permalink`, `categories`, `tags` — is filled in automatically and
written back into this file, so the values you see are the ones the build
committed. The `permalink` is the article's identity: it is what the URL is
built from, and it does not change when the file is renamed or moved.

## Adding another article

Create a sibling with the next number:

```
content/01.Notes/02.second-note.md
```

Leaving gaps (`10.`, `20.`, `30.`) makes inserting an article later a one-file
change rather than a renumbering of the whole directory.

## Translating this article

Add a sibling with a language suffix and the *same* number and title:

```
content/01.Notes/01.welcome.zh-Hans.md
```

Both files are then one article with one permalink and one comment thread. The
English version stays at the bare `/pages/…/` URL and the Chinese version is
served under `/zh-Hans/pages/…/`.

See the repository `README.md` for the full set of conventions.
